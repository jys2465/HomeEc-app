# 통합 가계부 v2 — 설치 가이드

구글 시트(`data`)를 **DB**로 쓰고, 앱은 **GitHub Pages**에서 호스팅합니다.  
설치는 **A(시트) → B(GitHub) → C(아이폰)** 순서로, 한 번만 하면 됩니다. (약 20~30분)

> 설계 의도는 `DESIGN.md` 에 있습니다. 여기서는 "어떻게 설치하는가"만 다룹니다.

---

## 0. 폴더 구성

```
index.html, manifest.json, sw.js, .nojekyll     ← 앱 (GitHub에 올리는 것)
css/ js/ icons/ assets/ vendor/                  ← 앱 (GitHub에 올리는 것)
apps-script/Code.gs, appsscript.json             ← 구글 시트에 붙여넣는 서버 코드 (GitHub에 올려도 무방, 비밀 없음)
README.md, DESIGN.md                             ← 설명서
```

앱 파일에는 **비밀번호·토큰·시트 주소가 하나도 들어 있지 않습니다.** 이 값들은 앱 화면(설정)에서 입력하고 **각자 기기에만** 저장됩니다. 그래서 저장소가 공개(Public)여도 안전합니다.

## A. 구글 시트 쪽 설치 (서버)

### A-1. Apps Script 열기
1. `05. 자산관리(NEW_12.1)` 시트를 엽니다.
2. 위쪽 메뉴 **확장 프로그램 → Apps Script**.

### A-2. 코드 붙여넣기
1. 왼쪽 `Code.gs` 를 열고, 안에 있는 **기존 코드를 전부 선택해서 지웁니다.** (`Ctrl+A` → `Delete`)  
   (기존 `filterDataToSummary` 기능은 새 코드 안에 **같은 이름으로 그대로** 들어 있어, 시트의 버튼/도형이 연결되어 있어도 계속 동작합니다.)
2. 이 폴더의 `apps-script/Code.gs` 내용을 **전체 복사 → 붙여넣기**.
3. 💾 저장 (`Ctrl+S`).

### A-3. 시간대 맞추기 (날짜가 하루 밀리는 문제 방지)
1. 왼쪽 ⚙ **프로젝트 설정** → "**'appsscript.json' 매니페스트 파일을 편집기에 표시**" 체크.
2. 왼쪽 파일 목록에 `appsscript.json` 이 생기면 열고, 내용을 `apps-script/appsscript.json` 으로 **교체** → 저장.  
   (핵심은 `"timeZone": "Asia/Seoul"` 입니다.)

### A-4. 초기 설정 실행 (`setup`)
1. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 ▶ **실행**.
2. **권한 검토**가 뜨면: `권한 검토` → 내 구글 계정 선택 →  
   "**Google에서 확인하지 않은 앱**" 경고가 나오면 **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**.  
   (내가 만든 스크립트가 내 시트를 읽고 쓰는 권한을 요청하는 것이라 정상입니다.)
3. 끝나면 시트 화면에 알림이 뜹니다. **"앱에 입력할 토큰" 40자리를 복사해 두세요.**  
   알림이 안 보이면 Apps Script 아래쪽 **실행 로그**에도 같은 내용이 나옵니다.  
   (나중에 시트 메뉴 **가계부 v2 → 앱 연결 토큰 보기**로 언제든 다시 볼 수 있습니다.)

`setup` 이 하는 일 (모두 안전하게 설계됨):
- `data` 시트 **A~K열은 건드리지 않고**, 오른쪽에 숨은 열 `id / rev / updated` 를 추가합니다. (예전 L열이 있으면 그 뒤에 붙고, L열은 앱이 사용하지 않습니다.)
- 모든 행에 고유 ID를 부여합니다.
- `changes`(변경 이력), `_ids`·`config`(숨김) 시트를 만듭니다.
- 매일 새벽 백업 + 정리, 매시간 `sumary` 갱신(바뀐 게 있을 때만) 자동 작업을 설치합니다.

### A-5. 웹 앱으로 배포 (앱이 접속할 주소 만들기)
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니(⚙) → 유형 **웹 앱**.
3. 설정:
   - 설명: `가계부 v2`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 반드시 이것 (토큰이 있어야만 데이터가 오가므로 안전합니다)
4. **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해 둡니다.

> 나중에 `Code.gs` 를 고치면: **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**.  
> (URL은 그대로 유지됩니다. "새 배포"를 만들면 URL이 바뀌니 주의하세요.)

### A-6. 예전 방식 끄기 (중요)
- 예전 **별도 프로젝트의 웹 앱**(예전 `Code.gs` + `SPREADSHEET_ID` 방식)이 있다면, 그 프로젝트에서 **배포 관리 → 보관(Archive)** 하세요.  
  예전 앱이 실수로 다시 열려도 시트를 덮어쓰지 못하게 막아 줍니다.
- 예전 프로젝트의 **트리거**(`backupDailyData` 등)도 삭제하세요. (새 코드가 대신합니다.)
- 예전 앱(Gemini 버전/이전 `index.html`)은 더 이상 쓰지 마세요.

### A-7. 확인
- 시트 화면을 새로고침(F5)하면 메뉴에 **가계부 v2** 가 생깁니다.
- 브라우저 주소창에 웹 앱 URL을 열어 `{"ok":true,"app":"gagyebu","v":2,…}` 가 보이면 서버 준비 완료입니다. (데이터는 절대 보이지 않습니다.)

## B. GitHub 쪽 설치 (앱 호스팅)

### B-1. 저장소 만들기
1. [github.com](https://github.com) 로그인 → 오른쪽 위 **＋ → New repository**.
2. Repository name: `gagyebu` (원하는 이름 가능), **Public** 선택 → **Create repository**.  
   (무료 계정의 GitHub Pages는 Public 저장소에서만 됩니다. 앱 파일에 비밀이 없으므로 괜찮습니다.)

### B-2. 파일 올리기
1. 받은 `gagyebu-v2.zip` 을 **압축 해제**합니다.
2. 저장소 화면에서 **uploading an existing file** 링크 클릭.
3. 압축을 푼 폴더 **안에 있는 모든 파일과 폴더**(`index.html`, `css`, `js`, `icons`, `assets`, `vendor`, `sw.js`, `manifest.json`, `apps-script` …)를 **끌어다 놓기**.  
   ⚠ 폴더 자체가 아니라 **그 안의 내용물**을 올려서, 저장소 맨 위에 `index.html` 이 보여야 합니다.
4. `.nojekyll` 파일은 숨김 파일이라 안 보일 수 있습니다. (없어도 동작합니다.)
5. 아래 **Commit changes** 클릭.

> 폴더 끌어놓기가 안 되면: **GitHub Desktop**(폴더를 저장소에 복사 → Commit → Push) 또는 git 명령을 쓰세요.
> ```
> git clone https://github.com/<아이디>/gagyebu.git
> (압축 푼 내용을 clone 폴더에 복사)
> git add . && git commit -m "가계부 v2" && git push
> ```

### B-3. Pages 켜기
1. 저장소 **Settings → Pages**.
2. **Build and deployment → Source: Deploy from a branch**.
3. **Branch: `main` / `/ (root)`** → **Save**.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다: **`https://<아이디>.github.io/gagyebu/`**
5. 주소를 열어 PIN 설정 화면이 보이면 성공입니다.

## C. 아이폰 설치

1. **사파리**로 `https://<아이디>.github.io/gagyebu/` 를 엽니다. (크롬 등은 홈 화면 앱이 제대로 안 됩니다)
2. **공유 버튼(□↑) → 홈 화면에 추가 → 추가**.
3. **홈 화면에 생긴 가계부 아이콘으로 실행**합니다.  
   ⚠ 아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로일 수 있어서, **홈 화면 아이콘으로 처음 열었을 때** 아래 4~5를 하세요. (내역은 시트에서 자동으로 내려오니 걱정 없습니다.)
4. **PIN 설정**: 숫자 4~8자리를 두 번 입력합니다. (고정 PIN은 없습니다. 잊으면 잠금 화면의 "PIN을 잊었어요"로 이 기기만 초기화하고 시트에서 다시 받으면 됩니다.)
5. **설정 탭 → 구글 시트 연결**: A-5의 **웹 앱 URL**, A-4의 **토큰** 입력 → **저장하고 연결 테스트**.  
   "연결됐어요" 후 내역이 내려오고, 홈 화면에 속도계가 나타납니다.
6. 두 번째 기기(아이패드, 노트북 브라우저 등)도 같은 방식으로 연결하면 같은 시트를 함께 씁니다.

## E. 평소 사용 팁

- **입력**: ＋ 버튼 → 금액부터 눌러도 됩니다. **내용**을 쓰면 항목·계정·반복이 자동으로 채워져요. 카드 승인 문자는 "더보기 → 문자 붙여넣기".
- **되돌리기**: 저장/삭제/복사 직후 아래에 뜨는 "되돌리기"를 누르세요.
- **고정비 복사**: 내역 탭 → "고정비 복사" → 미리보기에서 확인 → 복사 (★회차 자동 증가, 이미 있는 건 건너뜀).
- **오프라인**: 지하철처럼 연결이 없어도 입력됩니다. 연결되면 자동으로 올라갑니다. (상단 칩에 "대기 N건")
- **시트에서 직접 고쳐도 됩니다.** 값 수정·행 추가·행 삭제 모두 다음 동기화에 앱에 반영됩니다.
- ⚠ 시트에서 **하지 말 것**: `data` 의 **A~K열 순서/의미 변경**, 숨은 열 `id`·`rev`·`updated` 삭제(지우면 다시 만들어지지만 변경 이력이 초기화됨).
- **데이터가 사라질까 걱정될 때**: 매일 새벽 `yymmdd` 이름의 백업 시트가 자동으로 생깁니다. 대량 삭제·가져오기 직전에는 `yymmdd_HHmmss` 백업이 추가로 만들어집니다.

## F. 업데이트하는 법

**앱 파일을 고쳤을 때**
1. GitHub 저장소에 수정한 파일을 덮어쓰기 업로드(Commit).
2. **`sw.js` 맨 위의 `VERSION` 숫자를 하나 올립니다.** (예: `'2.0.0-1'` → `'2.0.0-2'`)
3. 앱을 열면 "새 버전이 준비됐어요 · **지금 적용**" 이 뜹니다.

**서버 코드(`Code.gs`)를 고쳤을 때**: A-5 아래의 "새 버전으로 배포" 순서를 따릅니다.

## G. 문제가 생기면

| 증상 | 원인/해결 |
|---|---|
| "토큰이 맞지 않아요" | 시트 메뉴 **가계부 v2 → 앱 연결 토큰 보기**로 다시 복사. 앞뒤 공백 주의 |
| "서버 응답을 읽을 수 없어요" | 배포의 **액세스 권한이 "모든 사용자"** 인지, URL이 `/exec` 로 끝나는지, **새 버전으로 배포**했는지 확인 |
| "서버 스크립트가 구버전이에요" | `Code.gs` 를 최신으로 붙여넣고 **새 버전 배포** |
| "서버가 다른 작업 중이에요" | 동시에 두 기기가 동기화 중. 몇 초 뒤 자동 재시도 |
| 날짜가 하루 어긋남 | A-3(시간대 `Asia/Seoul`) 확인. `setup` 알림에 두 시간대가 표시됨 |
| 앱이 "불러오는 중…"에서 멈춤 | ① 6초 뒤 화면에 **"불러오지 못한 파일"** 이 나오면 그 폴더(`js`, `css`, `icons`, `assets`, `vendor`)가 GitHub에 안 올라간 것입니다. 저장소 맨 위에 **폴더 5개 + 파일들**이 보여야 해요. (사파리/아이폰에서는 폴더 끌어놓기가 안 되니 PC의 크롬·엣지로 올리거나 GitHub Desktop 사용) ② 주소창에 `…github.io/저장소/js/util.js` 를 직접 열어 코드가 보이면 정상, "404"면 업로드 누락 ③ 파일을 고쳐 올린 뒤에도 그대로면 홈 화면 앱을 완전히 종료하고 다시 열거나, 아직 연결 전이라면 홈 화면 아이콘을 지우고 사파리에서 다시 추가 |
| 앱이 옛날 화면 | `sw.js` 의 `VERSION` 을 올렸는지, 앱을 완전히 종료 후 다시 실행 |
| PIN을 잊음 | 잠금 화면 **PIN을 잊었어요 → 이 기기 초기화** → 다시 PIN 설정 → 시트 재연결 (시트 데이터는 그대로) |
| "한 번에 너무 많은 내역을 지우려고…" | 서버의 안전장치(기본 30건). 앱의 "월 내역 삭제"/엑셀 대체는 확인 후 자동으로 허용 범위(최대 600건)와 백업이 적용됩니다 |
| 시트 대조에서 차이가 남 | 시트 `sumary` 가 오래된 경우가 대부분: 메뉴 **요약(sumary) 새로고침** 후 다시 대조 |

## H. 보안 메모 (솔직하게)

- **토큰**: 웹 앱 URL은 "모든 사용자" 접근이라, **토큰이 유일한 열쇠**입니다. 토큰을 남에게 보내지 마세요. 유출이 의심되면 시트 메뉴 **토큰 새로 만들기** → 각 기기에서 다시 입력.
- **PIN**: 화면을 가리는 잠금이며 데이터 **암호화는 아닙니다.** 기기 자체 잠금(Face ID/암호)과 함께 쓰세요. PIN은 소금+PBKDF2 해시로만 저장되고, 5회 틀리면 대기 시간이 생깁니다.
- 시트 자체의 공유 설정(누구와 공유했는지)도 가끔 확인하세요.
